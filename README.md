🏋️ Gym Workout Tracker

A modern gym workout tracking web application that allows users to create personalized training routines, execute workouts in real time, and track progress over time.
Built with a clean UI, intuitive UX, and scalability in mind.

🚀 Features

Dashboard

Overview of routines, recent workouts, and activity stats

Custom Routines

Create, edit, and delete workout routines

Fully customizable exercises, sets, reps, and rest times

Routine Builder

Drag-and-drop or structured routine creation

Exercise ordering and easy modifications

Exercises Library

Centralized list of exercises

Reusable across multiple routines

Workout Execution (Start Workout Flow)

Step-by-step workout execution

Track sets, reps, weights, and rest timers

Mark exercises and workouts as completed

Progress Tracking

Workout history

Performance tracking per exercise

🧠 Project Goals

Provide an easy-to-use gym tracker without unnecessary complexity

Focus on user experience and performance

Make the project scalable and extensible for future features such as:

Statistics & charts

User authentication

Cloud sync

Mobile support

🛠 Tech Stack

Frontend: React / Next.js

UI: Tailwind CSS + modern component system

State Management: React hooks / context

Backend (optional / planned): API-based architecture

Database (optional / planned): Relational or NoSQL (depending on implementation)

📦 Installation

Clone the repository

Install dependencies

npm install


Run the development server

npm run dev


Open in your browser

http://localhost:3000
